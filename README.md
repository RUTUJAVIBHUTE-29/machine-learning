# 🍎 Food Calorie Tracker

This project recognizes food items from images and estimates their calorie content using a pre-trained deep learning model (MobileNetV3).

## 🚀 Features
- Recognizes food from images
- Estimates calories using `nutrition_db.json`
- Displays results with images and labels

## 📂 Project Structure
- `FoodCalorieTracker.ipynb` → Jupyter Notebook with full code
- `nutrition_db.json` → Nutrition database
- `images/` → Sample food images
- `requirements.txt` → Dependencies
